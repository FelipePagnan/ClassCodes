----------------------------------------------------------- CHAVES PRIMARIAS -------------------------------

As chaves primeias de uma tabela tem o objetivo de tornar um registro unico dentro de um conjunto de registro de uma tabela. Uma PK
é conhecida como uma superchave, devido a seu objetivo, a superchave pode ser formada por apenas um atributo ou grupo de atributos de
uma tabela. É importante salientar que uma chave primaria pode ser fruto de uma chave estrangeira de uma outra tabela. As PKs recebem
restrições de UNIQUE e NOT NULL assim as chaves primarias e a tebela são criadas.

--------------------------------------------------------- CHAVES ESTRANGEIRAS ------------------------------

As chaves estrangeiras tem como papel permitir o relacionamento entre as tabelas, com isso quando uma FK é referenciada a partir de um
PK é criada uma restrição relacional, no qual os dados desta coluna precisam estar dentro do grupo de dados da tabela originail da chave 
primaria. Em suma, ao preencher com dados a FK é necessário que sejam os mesmos dados da tebale original, que no caso é a PK. As chaves
estrangeiras podem ser nulas de acordo com os desenhos de negocio dos bancos de dados. Ademais, quando se referencia uma FK é necessário
que os tipos dos atributos e precisões sejam iguais a orgiem, além disso é visto como uma boa prática repetir o nome da coluna e se 
adicionar o FK no inicio do nome do atributo. As FK quando referenciadas em uma tabela ela gera restrições em determinadas transações.


----------------------------------------------------------- COMANDOS SQL ------------------------------------

NO ACTION - A transação que viola a integridade é rejeitada e as alterações são revertidas

CASCADE - As linhas correspondentes são atualizas ou exlcuidas na tabela de referencia quando essa linha é atualizada ou excluidas na 
tabela pai. CASCADE não poderá ser especificada se uma coluna timestamp fizer parte da chave estrangeira ou da chave referenciada. 
	Combinações ON DELETE CASCADE, ON UPDATE CASCADE

SET NULL - Todos os valores que compõem a chave estrangeira são definidos como NULL quando a linha correspondente da tabela pai é
atualizada ou excluida. Para que essa restição seja executada, as colunas de chave estrangeira devem ser anuláveis. 
	Combinações ON DELETE SET NULL, ON UPDATE SET NULL

SET DEFAULT - Todos os valoes que compõem a chave estrangeira serão definidos com seus valores padrão se a linha correspondente na 
tabela pai for atualizada ou excluida. Para que essa restrição seja executada, todas as colunas de chave estrangeiras devem ter 
definições padrão. Se a coluna for anulável e não houver nenhum valor padrão explícito definido, NULL se tornará o valor padrão
implicito para a coluna. 
	Exemplo de deafult COLUMN_B INT DEFAULT 50.

TRUNCATE - O comando TRUNCATE tem como objetivo permitir a exclusão a nível de registros de uma tabela, mas diferente do comando DELETE, 
não é possível por uma cláusula WHERE para filtrar registros específicos. O filtro que é permitido é o de partição, só é possível 
aplicar esse filtro de particionamento se o banco de dados tiver essa funcionalidade ativada. Outro ponto importante é que o TRUNCATE é 
mais performático que o DELETE, pois faz a exclusão dos registros de uma vez, já o DELETE faz um por vez. É importante lembrar que a 
transação de TRUNCATE também respeita as restrições nas quais a tabela é estendida, como a restrição relacional das chaves estrangeiras. 
Além disso, não será possível reverter a operação de TRUNCATE com o ROLLBACK.

INSERT - O comando INSERT gera uma solicitação para inserir dados na tabela, essa inserção deve respeitar as restrições contidas na tabela.
Logo se as colunas possuem FK, CHECK, NOT NULL, no momento da inserção dos dados as informações selecionada para preencher a tabela devem 
respeitar as CONSTRAINT estabelecidas. Agora que entendemos como o INSERT se comporta, vamos ver quais as possibilidades de INSERT podemos
utilizar para gerar o preenchimento de dados em uma relação.
	As formas para se fazer um INSERT são as seguintes:
		Declarando os atributos e valores na hora de fazer o INSERT - insert into graduacao_teste.curso (id_curso, titulo, nome_departamento, 
		creditos) values ('100', 'Programming', 'Comp. Sci.', 4)
		Declarando apenas os valores que deseja inserir na tabela - insert into graduacao.curso values ('100','Programming', 'Comp. Sci.', 4)
	
	As formas para se fazer um INSERT são as seguintes:
	Utilizando o resultado de uma query como origem para o INSERT
		insert into graduacao.instrutor
			select id_aluno, nome, nome_departamento, 36000 as salario
			from graduacao.aluno
			where nome_departamento = 'Civil Eng.';	
			
UPDATE - O comando UPDATE gera uma solicitação para atualizar os dados de uma tabela, essa inserção deve respeitar as restrições contidas na 
tabela .Logo se as colunas possuem FK, CHECK, NOT NULL, no momento da atualização dos dados os valores selecionados para serem atualizados 
devem respeitar as CONSTRAINT estabelecidas. Agora vamos ver como podemos atualizar valores de uma tabelas.
	As formas para se fazer um UPDATE são as seguintes:
		Fazendo uma atualização sem filtros no UPDATE, gerando uma mudança em todos os valores da colunaupdate
			graduacao.instrutor
			set salario = salario * 1.05;
			
	Fazendo uma atualização da cláusula CASE no UPDATE, gerando várias mudanças nos valores de acordo com as condições estabelecidas no CASE.
		update graduacao.instrutor
		set salario = case
		when salario <= 100000 then salario * 1.05
		else salario * 1.03
		end;	
		
DELETE - O comando DELETE como vimos na última aula, tem como objetivo permitir a exclusão a nível de registros de uma tabela. E esse comando 
faz a exclusão dos registros de uma tabela de forma total ou mediante aos filtros de uma cláusula WHERE. É importante lembrar que a transação 
de exclusão de registros também respeita as restrições nas quais a tabela é estendida, como a restrição relacional das chaves estrangeiras. 
Além disso, se o banco de dados estiver com a configuração de COMMIT automático, será possível reverter qualquer erro usando o comando ROLLBACK. 
Exemplos de utilização do comando
	delete from graduacao.professor;
	delete from graduacao.professor where ano = 2007 and id_professor = '14365';
